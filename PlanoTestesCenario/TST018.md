## TST018 Ponto com defeito

**Caso de uso em que se baseia:** UC04 Fazer Check-in / Atualizar Status do Ponto

**Cenário:** Exceção A1 (motorista relata ponto com defeito)

**Preparação:**

a) Os seguintes pontos deverão estar cadastrados no sistema:

| Nome | Status atual | Último check-in |
| ---- | ------------ | --------------- |
| Eletroposto Ibirapuera | Ocupado | TST017, há poucos minutos |

b) As seguintes credenciais deverão estar cadastradas no sistema:

* E-mail: motorista@voltmap.com
* Senha: voltmap123

c) A localização do navegador está definida como no TST005 (-23.5646, -46.6527), com o acesso à localização permitido novamente após o TST009.

**Passos para execução do teste:**

1. Acessar a página inicial da aplicação VoltMap.
2. Se o topo mostrar "Entrar", tocar nele e entrar com as credenciais do item (b) da preparação.
3. Na lista do mapa, tocar em "Eletroposto Ibirapuera" para abrir a página do ponto.
4. Em "Fazer check-in", tocar em "Fora de serviço".
5. Entrar "Carregador não liga" no campo "Comentário (opcional)".
6. Tocar em "Confirmar Check-in".

**Resultado esperado:**

a) O sistema apresenta a mensagem:
> **"Obrigado! O ponto foi marcado como fora de serviço e sinalizado para verificação."**

b) O status do ponto passa a ser **Fora de serviço**.

c) O check-in aparece em primeiro lugar em "Check-ins recentes", com o selo Fora de serviço e o comentário "Carregador não liga".

**Resultado obtido:**

(   ) Sucesso  
(   ) Não executado  
(   ) Falha  
(   ) Cancelado
