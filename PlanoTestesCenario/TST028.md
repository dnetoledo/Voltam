## TST028 Arquivar denúncia

**Caso de uso em que se baseia:** UC05 Moderar Denúncias

**Cenário:** Fluxo principal, decisão "arquivar"

**Preparação:**

a) O banco de teste é o mesmo usado de TST001 a TST020 (criado com `npm run db:setup`), no estado deixado pelo script anterior. Há uma denúncia pendente de "Informação incorreta" sobre o ponto "Posto Rápido Rebouças" (status Disponível).

b) As seguintes credenciais deverão estar cadastradas no sistema:

* E-mail: admin@voltmap.com (administrador)
* Senha: voltmap123

**Passos para execução do teste:**

1. Acessar a aplicação VoltMap e entrar com as credenciais do item (b) da preparação.
2. No Painel administrativo, em Denúncias, tocar na denúncia sobre "Posto Rápido Rebouças".
3. Tocar em "Arquivar denúncia".
4. Na janela de confirmação, tocar em "Confirmar".

**Resultado esperado:**

a) Após o passo 2, o sistema mostra o conteúdo denunciado, o motivo, o ponto relacionado e o status do ponto.

b) Após o passo 4, o sistema apresenta a mensagem:
> **"Denúncia arquivada sem ação."**

c) O número de denúncias pendentes diminui em 1.

d) O ponto "Posto Rápido Rebouças" continua Disponível.

**Resultado obtido:**

( X ) Sucesso  
(   ) Não executado  
(   ) Falha  
(   ) Cancelado

**Descrição do resultado obtido:**

Confirmação "Arquivar a denúncia sem nenhuma ação?"; mensagem "Denúncia arquivada sem ação."; denúncias pendentes passaram de 5 para 4; denúncia ARQUIVADA; o ponto continuou DISPONIVEL.
