## TST035 Autor denuncia o próprio ponto

**Caso de uso em que se baseia:** RF10 Denunciar informação incorreta ou avaliação inadequada

**Cenário:** Regra: o autor pode denunciar o próprio ponto, por exemplo quando o local fechou (Tabela 16, revisão de 18/11/2026)

**Preparação:**

a) O banco de teste é o mesmo usado de TST001 a TST020 (criado com `npm run db:setup`), no estado deixado pelo script anterior. O ponto "Supermercado Vila Madalena" foi cadastrado pela conta motorista@voltmap.com (como todos os pontos do `npm run db:setup`).

b) As seguintes credenciais deverão estar cadastradas no sistema:

* E-mail: motorista@voltmap.com
* Senha: voltmap123

**Passos para execução do teste:**

1. Acessar a página inicial da aplicação VoltMap.
2. Se o topo mostrar "Entrar", tocar nele e entrar com as credenciais do item (b) da preparação.
3. Na lista do mapa, tocar em "Supermercado Vila Madalena".
4. Tocar em "⚑ Denunciar ponto inexistente ou informação incorreta".
5. Escolher o motivo "Ponto inexistente".
6. Entrar "O supermercado fechou e o carregador foi retirado" em "Detalhes".
7. Tocar em "Enviar denúncia".

**Resultado esperado:**

a) O sistema apresenta a mensagem:
> **"Denúncia enviada. Obrigado! Um administrador vai analisar o conteúdo."**

b) Uma nova denúncia pendente sobre o ponto é gravada e aparece no Painel administrativo.

**Resultado obtido:**

( X ) Sucesso  
(   ) Não executado  
(   ) Falha  
(   ) Cancelado

**Descrição do resultado obtido:**

A página do ponto mostrou "Denúncia enviada. Obrigado! Um administrador vai analisar o conteúdo."; o total de denúncias passou de 4 para 5 (PONTO, Supermercado Vila Madalena, PONTO_INEXISTENTE, PENDENTE, denunciante motorista@voltmap.com); a denúncia aparece no Painel administrativo.
