## TST004 Duplicidade: cadastrar mesmo assim

**Caso de uso em que se baseia:** UC03 Cadastrar Novo Ponto de Recarga

**Cenário:** Exceção A1 (ponto muito próximo de um já existente), opção "Cadastrar mesmo assim"

**Preparação:**

a) O banco de dados de teste foi criado com `npm run db:setup` (12 pontos de exemplo) e contém **14** pontos. Pontos relevantes para este teste:

| Nome | Latitude | Longitude | Conector | Potência | Status |
| ---- | -------- | --------- | -------- | -------- | ------ |
| Eletroposto Paulista Center | -23.56460 | -46.65270 | Tipo 2, CCS Combo | 60 kW | Disponível |
| Recarga Teste Sul Paulista | -23.56506 | -46.65270 | Tipo 2 | 22 kW | Não verificado |
| Box | -23.55000 | -46.64000 | CCS Combo | 1000 kW | Não verificado |

b) As seguintes credenciais deverão estar cadastradas no sistema:

* E-mail: motorista@voltmap.com
* Senha: voltmap123

**Passos para execução do teste:**

1. Acessar a página inicial da aplicação VoltMap.
2. Tocar em "Entrar" e entrar com as credenciais do item (b) da preparação.
3. Tocar em "＋ Adicionar ponto".
4. Arrastar o marcador até a dica mostrar "Local: -23.56416, -46.65270".
5. Entrar "Recarga Teste Norte Paulista" no campo "Nome do local".
6. Selecionar o conector "Tipo 2".
7. Entrar 22 no campo "Potência (kW)".
8. Entrar 1 no campo "Vagas".
9. Tocar em "Salvar Ponto de Recarga".
10. Na janela de alerta, tocar em "Cadastrar mesmo assim".


**Resultado esperado:**

a) Após o passo 9, o sistema abre a janela "Possível ponto duplicado" com a mensagem:
> **"Já existe um ponto de recarga muito próximo deste local. Deseja cadastrar mesmo assim?"**

b) Após o passo 10, o sistema abre a página do ponto e apresenta a mensagem:
> **"Ponto cadastrado com sucesso! Ele aparece para os outros motoristas como "Não verificado"."**

c) Um novo ponto está cadastrado com as seguintes informações:

| Nome | Latitude | Longitude | Conector | Potência | Status |
| ---- | -------- | --------- | -------- | -------- | ------ |
| **Recarga Teste Norte Paulista** | **-23.56416** | **-46.65270** | **Tipo 2** | **22 kW** | **Não verificado** |

d) O banco passa a ter **15** pontos.

**Resultado obtido:**

(   ) Sucesso  
(   ) Não executado  
(   ) Falha  
(   ) Cancelado
