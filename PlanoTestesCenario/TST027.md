## TST027 Painel acessado por motorista

**Caso de uso em que se baseia:** UC05 Moderar Denúncias

**Cenário:** Exceção: acesso de quem não é administrador (Tabela 13)

**Preparação:**

a) O banco de teste é o mesmo usado de TST001 a TST020 (criado com `npm run db:setup`), no estado deixado pelo script anterior.

b) As seguintes credenciais deverão estar cadastradas no sistema:

* E-mail: motorista@voltmap.com
* Senha: voltmap123

**Passos para execução do teste:**

1. Acessar a aplicação VoltMap e entrar com as credenciais do item (b) da preparação.
2. Abrir o endereço do painel administrativo (admin.html).

**Resultado esperado:**

a) O sistema apresenta a mensagem:
> **"Acesso permitido somente ao administrador."**

b) Nenhuma denúncia ou usuário é exibido.

**Resultado obtido:**

( X ) Sucesso  
(   ) Não executado  
(   ) Falha  
(   ) Cancelado

**Descrição do resultado obtido:**

Ao abrir o painel com a conta de motorista: "Acesso permitido somente ao administrador." e o botão "Voltar ao mapa".
