## TST024 Denúncia de avaliação

**Caso de uso em que se baseia:** RF10 Denunciar informação incorreta ou avaliação inadequada

**Cenário:** Fluxo principal

**Preparação:**

a) O banco de teste é o mesmo usado de TST001 a TST020 (criado com `npm run db:setup`), no estado deixado pelo script anterior. O "Eletroposto Ibirapuera" tem uma avaliação de João Motorista ("Às vezes tem fila no fim de semana."), ainda não denunciada pelo motorista.

b) As seguintes credenciais deverão estar cadastradas no sistema:

* E-mail: motorista@voltmap.com
* Senha: voltmap123

**Passos para execução do teste:**

1. Acessar a página inicial da aplicação VoltMap.
2. Se o topo mostrar "Entrar", tocar nele e entrar com as credenciais do item (b) da preparação.
3. Na lista do mapa, tocar em "Eletroposto Ibirapuera".
4. Na avaliação de João, tocar em "⚑ Denunciar".
5. Escolher o motivo "Avaliação ofensiva ou inadequada".
6. Entrar "Comentário sem relação com o ponto (teste)" em "Detalhes".
7. Tocar em "Enviar denúncia".

**Resultado esperado:**

a) O sistema apresenta a mensagem:
> **"Denúncia enviada. Obrigado! Um administrador vai analisar o conteúdo."**

b) Uma nova denúncia pendente é gravada.

**Resultado obtido:**

( X ) Sucesso  
(   ) Não executado  
(   ) Falha  
(   ) Cancelado

**Descrição do resultado obtido:**

Mensagem "Denúncia enviada. Obrigado! Um administrador vai analisar o conteúdo."; o total de denúncias passou de 4 para 5.
