## TST022 Nova avaliação do mesmo motorista

**Caso de uso em que se baseia:** RF08 Avaliar Ponto de Recarga

**Cenário:** Regra: uma avaliação por motorista em cada ponto (Tabela 16)

**Preparação:**

a) O banco de teste é o mesmo usado de TST001 a TST020 (criado com `npm run db:setup`), no estado deixado pelo script anterior. O ponto "Estacionamento Higienópolis" tem 1 avaliação, de 4 estrelas, feita pelo motorista no TST021.

b) As seguintes credenciais deverão estar cadastradas no sistema:

* E-mail: motorista@voltmap.com
* Senha: voltmap123

**Passos para execução do teste:**

1. Acessar a página inicial da aplicação VoltMap.
2. Se o topo mostrar "Entrar", tocar nele e entrar com as credenciais do item (b) da preparação.
3. Na lista do mapa, tocar em "Estacionamento Higienópolis".
4. Em "Avaliações", tocar na 2ª estrela.
5. Entrar "Só 1 das 2 vagas funcionando" no campo de comentário.
6. Tocar em "Atualizar avaliação".

**Resultado esperado:**

a) Antes do passo 4, o botão de envio mostra "Atualizar avaliação".

b) O sistema apresenta a mensagem "Avaliação publicada. Obrigado!".

c) A nota média passa a ser 2 e o ponto continua com "1 avaliação" (a anterior é atualizada, não duplicada).

**Resultado obtido:**

( X ) Sucesso  
(   ) Não executado  
(   ) Falha  
(   ) Cancelado

**Descrição do resultado obtido:**

O botão aparecia como "Atualizar avaliação". Mensagem "Avaliação publicada. Obrigado!"; nota média 2; o ponto continuou com 1 avaliação (a anterior foi atualizada).
