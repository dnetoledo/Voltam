## TST031 Reativar ponto suspenso

**Caso de uso em que se baseia:** UC05 Moderar Denúncias

**Cenário:** Pós-condição A2: ponto suspenso até nova verificação (Tabela 16)

**Preparação:**

a) O banco de teste é o mesmo usado de TST001 a TST020 (criado com `npm run db:setup`), no estado deixado pelo script anterior. O "Hotel Jardins Carregador" está suspenso (TST030).

b) As seguintes credenciais deverão estar cadastradas no sistema:

* E-mail: admin@voltmap.com (administrador)
* Senha: voltmap123

**Passos para execução do teste:**

1. Acessar a aplicação VoltMap e entrar com as credenciais do item (b) da preparação.
2. No Painel administrativo, abrir "Pontos suspensos".
3. Na linha de "Hotel Jardins Carregador", tocar em "Reativar ponto".
4. Sem login, fazer a busca pela localização atual (como no TST005).

**Resultado esperado:**

a) Após o passo 3, o sistema apresenta a mensagem:
> **"Ponto reativado. Ele volta a aparecer nas buscas como "não verificado"."**

b) A lista de pontos suspensos fica vazia.

c) Após o passo 4, "Hotel Jardins Carregador" volta a aparecer, como Não verificado.

**Resultado obtido:**

( X ) Sucesso  
(   ) Não executado  
(   ) Falha  
(   ) Cancelado

**Descrição do resultado obtido:**

Mensagem "Ponto reativado. Ele volta a aparecer nas buscas como "não verificado"."; a lista de suspensos ficou vazia; a busca voltou a 15 pontos, com Hotel Jardins Carregador como Não verificado.
