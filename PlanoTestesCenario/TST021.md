## TST021 Avaliação bem-sucedida

**Caso de uso em que se baseia:** RF08 Avaliar Ponto de Recarga

**Cenário:** Fluxo principal

**Preparação:**

a) O banco de teste é o mesmo usado de TST001 a TST020 (criado com `npm run db:setup`), no estado deixado pelo script anterior. O ponto "Estacionamento Higienópolis" não tem avaliações.

b) As seguintes credenciais deverão estar cadastradas no sistema:

* E-mail: motorista@voltmap.com
* Senha: voltmap123

**Passos para execução do teste:**

1. Acessar a página inicial da aplicação VoltMap.
2. Se o topo mostrar "Entrar", tocar nele e entrar com as credenciais do item (b) da preparação.
3. Na lista do mapa, tocar em "Estacionamento Higienópolis".
4. Em "Avaliações", tocar na 4ª estrela.
5. Entrar "Vagas cobertas e bem iluminadas" no campo de comentário.
6. Tocar em "Publicar avaliação".

**Resultado esperado:**

a) O sistema apresenta a mensagem:
> **"Avaliação publicada. Obrigado!"**

b) A nota média do ponto passa a ser 4, com "1 avaliação".

c) A avaliação aparece na lista do ponto, com o comentário "Vagas cobertas e bem iluminadas".

**Resultado obtido:**

( X ) Sucesso  
(   ) Não executado  
(   ) Falha  
(   ) Cancelado

**Descrição do resultado obtido:**

Mensagem "Avaliação publicada. Obrigado!"; nota média 4 com "1 avaliação"; a avaliação aparece na lista do ponto com o comentário.
