## TST026 Denúncia do próprio conteúdo

**Caso de uso em que se baseia:** RF10 Denunciar informação incorreta ou avaliação inadequada

**Cenário:** Exceção: denúncia do próprio conteúdo (Tabela 13)

**Preparação:**

a) O banco de teste é o mesmo usado de TST001 a TST020 (criado com `npm run db:setup`), no estado deixado pelo script anterior. O ponto "Recarga Teste Sul Paulista" foi cadastrado pelo próprio motorista no TST010.

b) As seguintes credenciais deverão estar cadastradas no sistema:

* E-mail: motorista@voltmap.com
* Senha: voltmap123

**Passos para execução do teste:**

1. Acessar a página inicial da aplicação VoltMap.
2. Se o topo mostrar "Entrar", tocar nele e entrar com as credenciais do item (b) da preparação.
3. Na lista do mapa, tocar em "Recarga Teste Sul Paulista".
4. Tocar em "⚑ Denunciar" (abaixo de "Como chegar").
5. Escolher o motivo "Informação incorreta".
6. Tocar em "Enviar denúncia".

**Resultado esperado:**

a) O sistema apresenta a mensagem:
> **"Você não pode denunciar um conteúdo que você mesmo enviou."**

b) Nenhuma denúncia nova é gravada.

**Resultado obtido:**

(   ) Sucesso  
(   ) Não executado  
( X ) Falha  
(   ) Cancelado

**Descrição do resultado obtido:**

O sistema aceitou a denúncia do próprio ponto: a janela fechou, a página mostrou "Denúncia enviada. Obrigado! Um administrador vai analisar o conteúdo." e o total de denúncias passou de 5 para 6 (denúncia PONTO 13, PENDENTE). Esperado: "Você não pode denunciar um conteúdo que você mesmo enviou." No código, a regra exclui de propósito o tipo PONTO (Motorista.registrarDenuncia), o que contradiz a regra "denúncia do próprio conteúdo" da Tabela 13. O grupo deve decidir se corrige o código ou a especificação.
