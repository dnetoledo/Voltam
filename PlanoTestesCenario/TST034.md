## TST034 Administrador não pode ser bloqueado

**Caso de uso em que se baseia:** RF12 Gerenciar usuários

**Cenário:** Exceção: bloquear a si mesmo ou outro administrador (Tabela 13)

**Preparação:**

a) O banco de teste é o mesmo usado de TST001 a TST020 (criado com `npm run db:setup`), no estado deixado pelo script anterior.

b) As seguintes credenciais deverão estar cadastradas no sistema:

* E-mail: admin@voltmap.com (administrador)
* Senha: voltmap123

**Passos para execução do teste:**

1. Acessar a aplicação VoltMap e entrar com as credenciais do item (b) da preparação.
2. No Painel administrativo, abrir "Usuários".

**Resultado esperado:**

a) A linha de "Administrador VoltMap" (admin@voltmap.com) não mostra o botão "Bloquear" nem "Desbloquear".

**Resultado obtido:**

( X ) Sucesso  
(   ) Não executado  
(   ) Falha  
(   ) Cancelado

**Descrição do resultado obtido:**

A linha do Administrador VoltMap não tem botão Bloquear/Desbloquear (0 botões).
