## TST003 E-mail não cadastrado

**Caso de uso em que se baseia:** UC01 Autenticar-se

**Cenário:** Exceção A1 (credenciais inválidas)

**Preparação:**

a) O banco de teste foi criado com `npm run db:setup`. O seguinte usuário deverá estar cadastrado, com status ATIVO:

| Nome | E-mail | Senha | Tipo | Status |
| ---- | ------ | ----- | ---- | ------ |
| Motorista Demonstração | motorista@voltmap.com | voltmap123 | MOTORISTA | ATIVO |

b) Nenhum usuário deverá estar logado no navegador (se houver, tocar em "Sair").

c) Não existe usuário com o e-mail naoexiste@voltmap.com.

**Passos para execução do teste:**

1. Acessar a página inicial da aplicação VoltMap.
2. Tocar em "Entrar" no topo da tela.
3. Entrar "naoexiste@voltmap.com" no campo "E-mail".
4. Entrar "voltmap123" no campo "Senha".
5. Tocar no botão "Entrar".

**Resultado esperado:**

a) O sistema apresenta a mensagem:
> **"E-mail ou senha inválidos."**

b) O sistema permanece na tela de login.

Observação: a mensagem é a mesma do TST002, para não revelar quais e-mails estão cadastrados.
